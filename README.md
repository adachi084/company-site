# スカイライン・テクノロジーズ 企業サイト

架空のソフトウェア開発会社「スカイライン・テクノロジーズ」のコーポレートサイトです。
HTML（`index.html`）、CSS（`css/style.css`）、JavaScript（`js/main.js`）で構成した、1ページのサイトです。

> このサイトは架空の企業のデモです。社名、代表者名、所在地、連絡先、実績の数値はすべて架空のものです。

## サイトの概要

建築の立面図をモチーフにしたデザインで、次のセクションで構成されています。

| セクション | 内容 |
| --- | --- |
| お知らせ | ナビゲーション直下に、日付・カテゴリ付きで最新のお知らせを表示 |
| ヒーロー | キャッチコピーと、スクリプトで描画する街並み（スカイライン）のイラスト |
| 事業内容 | クラウド基盤、データ・AI、業務システム、アプリ開発の4事業 |
| 実績 | 導入後の成果を数値で示した開発事例 |
| 進め方 | 地盤調査 → 基本設計 → 施工 → 竣工・運用 の4工程 |
| 会社概要 | 代表メッセージと会社情報 |
| 採用情報 | 募集職種と年収レンジ |
| お問い合わせ | 入力チェック付きのフォーム（デモのため実際には送信されません） |

### 主な特徴

- ライトモードとダークモードの両方に対応（OS の設定に追従します）
- スマートフォンの画面幅にも対応したレスポンシブデザイン
- ビルドや外部ライブラリは不要（フォントのみ Google Fonts から読み込み）

## ブラウザで開く手順

### 方法1：ファイルを直接開く

1. エクスプローラーで `company-site` フォルダを開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザ（Chrome、Edge など）でサイトが表示されます。

別のブラウザで開きたい場合は、`index.html` を右クリックして「プログラムから開く」でブラウザを選ぶか、ブラウザのウィンドウへファイルをドラッグ＆ドロップしてください。

### 方法2：コマンドから開く

PowerShell で `company-site` フォルダに移動し、次のコマンドを実行します。

```powershell
start index.html
```

macOS の場合は `open index.html` です。

### 方法3：ローカルサーバーで開く（任意）

Python がインストールされていれば、簡易サーバーを起動して確認することもできます。

```bash
python -m http.server 8000
```

起動後、ブラウザで <http://localhost:8000> にアクセスしてください。停止するには `Ctrl + C` を押します。

> フォント（Google Fonts）の読み込みにはインターネット接続が必要です。オフラインでもサイトは表示されますが、代替フォントで表示されます。
